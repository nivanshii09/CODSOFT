# ATM Interface (Java)

## Project Overview

The ATM Interface is a console-based Java application developed as part of the CodSoft Java Development Internship. It simulates the basic operations of an ATM using Object-Oriented Programming concepts.

The application allows users to perform banking operations such as checking their account balance, depositing money, withdrawing money, and viewing transaction history through a menu-driven interface.

---

## Features

- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Input validation
- Menu-driven interface
- Object-Oriented Programming (OOP)
