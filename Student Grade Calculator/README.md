# Student Grade Calculator

## Description
A Java console application that calculates a student's total marks, percentage, grade, and pass/fail status.

## Features
- Accepts student details
- Accepts subject names and marks
- Calculates total marks and percentage
- Assigns grades
- Displays highest and lowest marks
- Input validation

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## How to Run

```bash
javac *.java
java Main
```
