# Student Grade Calculator (Java)

## Project Overview

The Student Grade Calculator is a console-based Java application developed as part of the CodSoft Java Development Internship. It calculates the total marks, average percentage, and final grade based on the marks entered for multiple subjects.

The application demonstrates the use of Java programming fundamentals and Object-Oriented Programming concepts through a simple and interactive menu-driven program.

---

## Features

- Enter marks for multiple subjects
- Calculate total marks
- Calculate average percentage
- Display final grade
- Input validation
- Console-based user interface
- Object-Oriented Programming (OOP)

---

## Technologies Used

- Java
- VS Code
- Java OOP
- Scanner Class

---

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/CODSOFT.git
```

2. Open the project in VS Code.

3. Run `Main.java`.

4. Enter the number of subjects and their respective marks.

5. View the calculated results.

---

## Sample Output

```
========== Student Grade Calculator ==========

Enter the number of subjects: 5

Enter marks for Subject 1: 85
Enter marks for Subject 2: 92
Enter marks for Subject 3: 78
Enter marks for Subject 4: 88
Enter marks for Subject 5: 95

Total Marks: 438
Average Percentage: 87.60%
Grade: A
```

|------------|-------|
